💼 Data Science Salaries Explorer 2026

Interactive Streamlit dashboard analyzing global DS salaries from Kaggle 2025 dataset (11k+ rows). Filter by role (Data Engineer avg €85k Berlin), experience, remote/hybrid. Key insight: ML Engineers earn 20% more in Germany.

Features

Filters: Job title, experience level, company size/location.

Charts: Salary boxplots, heatmaps (Plotly/Altair).

Insights: Top paying roles, Berlin/Germany trends.

Export: Filtered CSV download.

Quick Start
git clone https://github.com/ritesh8303/data-science-salaries
cd data-science-salaries
pip install -r requirements.txt
streamlit run app.py

Dataset: salaries.csv (Kaggle: work_year, experience_level, employment_type, job_title, salary_in_usd, employee_residence, company_location, company_size).
